# English Wikipedia October 2026 Secure Timestamp
On November 18, 2026, we encoded the October 2026 plain text English language Wikipedia corpus into a Merkle tree and wrote the root hash on the Bitcoin blockchain in [block 976382](https://www.blockchain.com/explorer/transactions/btc/4df6415bb70a7b0dd191bbaa89abd515f9d062c478ee10317e0f08ea36971604). This comprises a secure timestamp of the Wikipedia corpus. In other words, the Merkle tree and the block containing its root hash provide cryptographic-strength proof that each English-language Wikipedia article existed in November 2026. 

Read more about how this works, and why we did it in the first place, [here](../overview.md).

## Corpus Details
This timestamp covers all English-language Wikipedia articles as of October 1, 2020. Each article is made available as an HTML file that can be opened in a web browser. The timestamped corpus does not include most non-text data (images, audio, etc).

We also recently timestamped a [January 2020 snapshot of Wikipedia](wiki2020en.md) as well.

### Provenance
The source data was obtained from the Internet Archive in early October 2026. See the explanatory document for details.

## Timestamp Details

This timestamp was produced with a prototype of the Amber secure timestamp utility. See the source code [here](https://github.com/tenchd/amber).
